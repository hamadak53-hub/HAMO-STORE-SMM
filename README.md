# HAMO STORE SMM

واجهة متجر عربية لخدمات السوشيال ميديا، مستقلة تمامًا عن أي مشروع آخر.

## الملفات
- `index.html` — هيكل الصفحة والمحتوى.
- `style.css` — التصميم المتجاوب للموبايل والكمبيوتر.
- `script.js` — التفاعل بين المنصات ومعاينة نموذج الطلب.

## تشغيل محلي
افتح `index.html` في المتصفح.

## النشر على Render
أنشئ **Static Site** واربط المستودع:
- Branch: `main`
- Build Command: اتركه فارغًا
- Publish Directory: `.`

بعدها اضغط Deploy. أي تحديث على فرع `main` يمكن نشره تلقائيًا عند تفعيل Auto-Deploy.

## حالة المشروع
النسخة الحالية واجهة أولية قابلة للتصفح. نموذج الطلب يعرض معاينة فقط ولا يرسل طلبات ولا يجمع مدفوعات بعد.

## المطلوب قبل تشغيل البيع الفعلي
1. قائمة الخدمات الحقيقية ومعرّفاتها وأسعارها وحدود الكميات.
2. بيانات مزود SMM API وطريقة التحقق من الرصيد وحالة الطلبات.
3. إعداد Backend وقاعدة بيانات لحفظ المستخدمين والطلبات.
4. اختيار وسائل الدفع بالجنيه المصري وتحديد آلية تأكيد الدفع.
5. لوحة تحكم للإدارة لمتابعة الطلبات وتعديل الخدمات والأسعار.

**مهم:** لا تضع مفاتيح API أو كلمات المرور داخل ملفات الواجهة الأمامية أو المستودع.
